# 同花亏 · 玩法与新手指引

> 这是一份"教你少亏一点"的说明书。

---

## 1. 这是什么

「同花亏」是一个**多人联网的股票交易商业模拟对战游戏**。全市场 **61 只虚构股票**（51 只 A 股 + 10 只纳斯达克股，含 30 只「社团概念股」）+ **4 大指数**。
界面和操作习惯照着 **Windows 完全版同花顺** 做：菜单栏、工具栏、多标签页、行情报价表、五档盘口、下单面板、K 线/分时图、状态栏大盘指数，一样不少。

它不是炒股软件，**所有股票代码、名称、行情、新闻都是虚构的**。你在这里亏掉的钱，一分都不是真的；你在这里练出来的手感，也许是真的。

## 2. 一局是怎么玩的

```
登录 → 对战大厅（选模式/时长/初始资金）→ 快速匹配或创建房间
     → 倒计时 3 秒 → 开盘（虚拟时钟开始走）→ 自由交易
     → 时间到 / 房主结束 → 结算页（名次 + 资产曲线 + ELO 变化）
```

* **胜负**：期末**总资产**最高者获胜。收益率 =（期末总资产 − 初始资金）/ 初始资金。
* **三种模式**
  | 模式 | 人数 | 结算方式 |
  |---|---|---|
  | 1v1 单挑 | 2 | 收益率高者胜 |
  | 多人混战 | 2~30 | 按收益率排名，两两配对算 ELO |
  | 红蓝团战 | 4~30 | 按**队伍平均收益率**判定队伍胜负 |
* **时长**：5 / 15 / 30 分钟（真实时间）。**1 秒 = 1 个虚拟分钟**，15 分钟的对局相当于虚拟市场里 3 个多交易日。
* **初始资金**：10 万 / 100 万 / 500 万。资金体量直接决定你的打法——500 万重仓买入会明显推高股价，这就是"资金冲击"。

## 3. 交易规则（和真实 A 股基本一致）

| 规则 | 说明 |
|---|---|
| **T+1** | 今天买的股票今天不能卖。下单面板的"可用"才是你能卖的。 |
| **涨跌停** | 主板 ±10%；创业板/科创板（`30`/`68` 开头）±20%。报价超出范围会被直接拒单。 |
| **交易单位** | 1 手 = 100 股，买入必须是 100 的整数倍；持仓不足 100 股时可以一次性全卖。 |
| **佣金** | 成交额 × 0.25‰，最低 5 元 |
| **印花税** | 卖出金额 × 0.5‰（只在卖出时收） |
| **过户费** | 成交额 × 0.01‰（双向） |
| **撮合** | 限价单先与市场合成流动性按对手价逐档成交（有滑点），再与其他玩家挂单按"价格优先、时间优先"撮合；没成交的部分挂在盘口排队。市价单立即吃对手五档，吃不完的自动撤单。 |
| **价格冲击** | 大额主动成交会推动股价：净买入推高、净卖出打压。**大单是有成本的。** |
| **挂单有效期** | 挂单超过 1 个虚拟交易日（240 分钟）未成交会自动撤单并解冻资金/股份。 |

```
┌ 标题栏：系统 功能 报价 分析 交易 资讯 工具 帮助 │ 全局搜索 │ ─ □ ✕ ┐
├ 工具栏：买入F1 卖出F2 撤单F3 │ 持仓F4 委托F5 成交F6 │ 分时 1分 5分 日K │ 排行榜 资讯 对战大厅 │
├ 标签栏：自选股 分时图 K线图 交易 排行 资讯 对战大厅（可关闭）
├── 左：行情报价表（点击切换股票，点列头排序，拖中间分隔条调宽）
├── 中：图表区（分时 / 1分 / 5分 / 15分 / 日K，滚轮缩放、拖拽平移、右键切指标）
├── 右：五档盘口 / 分时明细 / 下单面板
├── 底：持仓 · 委托 · 成交 · 资金 · 排行 · 资讯
└ 状态栏：连接状态 │ 同花综指·同花成指 │ 盘中时钟 延迟 在线人数 我的资产
```

**下单面板怎么用**
1. 左边行情表点一只股票（或按 `↑/↓` 切换）；
2. 点 `买入`(红) / `卖出`(绿) 切方向，或直接按 `F1`/`F2`；
3. 价格：点 `买一`/`卖一`/`涨停`/`跌停` 快捷填价，或用 `±` 步进；
4. 数量：按 `±100` 步进，或点 `1/4` `1/3` `1/2` `全仓` 一键算好手数；
5. 点大红/大绿按钮 → 弹二次确认 → 提交。回执会以右下角提示弹出。

## 6. AI 诊股（同花顺式智能投顾）

点工具栏 **✨ AI 诊股**（或底部标签栏「AI 诊股」），会打开两块内容：

### 6.1 个股诊断

对**当前选中的股票**出一份体检报告：

| 模块 | 说明 |
|---|---|
| **综合评分** | 0~100 分，圆环显示；评级分五档：强烈买入 / 谨慎买入 / 持有观望 / 逢高减仓 / 建议卖出 |
| **六维分项** | 估值 30% · 趋势 25% · 动量 15% · 量能 10% · 盘口 10% · 风险 10% |
| **判断依据** | 估值 / 趋势 / 动量 / 量能 / 盘口 / 当日涨跌，每条带 ▲利好 ▼利空 ▸中性 |
| **风险提示** | 距涨跌停距离、波动率、是否封板、成交是否枯竭等 |
| **持仓建议** | 已持仓时给出止盈/止损/减仓提示；未持仓显示「当前未持有」 |
| **操作建议** | 一句话动作 + 参考买入区间 + 止损价 + 止盈价，可一键填进下单面板 |

**其中「估值」这一项是别的软件给不了的**：本游戏的每只股票都有一条**内在价值线**（不受任何玩家买卖影响的基本面价值）。AI 会用现价和内在价值比较，得出高估/低估结论——所以当全场都在追高时，它会明确告诉你「股价已高出内在价值 X%，外部资金随时可能反向出货」。

### 6.2 大盘 AI 观点

- **市场情绪**：普涨格局 / 偏暖震荡 / 多空胶着 / 偏弱调整 / 恐慌杀跌，附一句操作提示
- **涨跌家数**：全市场多少涨、多少跌、涨停几家、跌停几家
- **板块**：领涨板块、领跌板块
- **AI 关注标的**：3 只评分最高的股票（低估 + 动量 + 流动性综合），点一下即可切过去看盘

> 评分与建议全部由**服务端**计算下发，客户端无法伪造，也看不到别人的持仓。

## 7. 新手三条保命建议

1. **先活着，再赚钱。** 别人的 30% 收益往往来自一次梭哈，但结算时爆仓的人不会出现在你的视野里——他们会出现在排行榜最后一行。
2. **别和 T+1 对着干。** 追高买入的当天你卖不掉，隔夜跳空全是你承担的。
3. **注意价格冲击。** 500 万本金重仓一只小盘股，你自己就是行情。分批建仓，成本会好看很多。

## 9. 常见问题

**Q：客户端连不上 / 一直显示"连接断开"？**
A：先看服务端是否在跑（Windows 上双击 `tools\start-windows.bat`）；局域网访问要用服务器 IP 而不是 `127.0.0.1`；还要放行防火墙 8899 端口（见 `docs/DEPLOY-WINDOWS.md`）。

**Q：为什么我买不到卖一价？**
A：限价单只有价格**不低于**卖一才会立即成交，否则会挂在买一排队等对手来吃你。市价单能立刻成交，但会吃穿档位、有滑点。

**Q：为什么我的收益率是负的，明明股票涨了？**
A：手续费。频繁交易的佣金+印花税会实打实吃掉收益。

**Q：能多人同时玩吗？**
A：能。同一房间最多 **30 人**（房主在「人数上限」里选 2~30；快速匹配默认 8 人），也可以一个服务器开多个房间同时进行。

**Q：界面数据是真的行情吗？**
A：不是。全部是服务端模拟生成的虚拟行情，与真实市场无关，不构成任何投资建议。
